# Digital Library

A web-based library management system that allows users to view, borrow, and manage books digitally.


## Features
 - User registration and login
- Admin dashboard for managing books
- Borrow and return functionality
- Search and filter books
- Responsive UI


## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
